# SAO Shopping

A simple online shopping website built with plain HTML, CSS and JavaScript.

## Features
- Product list with categories (Fashion, Electronics, Home, Beauty, Grocery)
- Search and sort (price, rating)
- Cart with quantity controls, saved in the browser
- Free delivery above ₹499
- Works on mobile and desktop

## How to run
Open `index.html` in any browser. No setup needed.

## How to change products
Edit the `PRODUCTS` list at the top of `script.js`.
